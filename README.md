# FLOW CLASS · Power Automate 첫걸음

처음 배우는 사람과 처음 가르치는 사람을 위한 한국어 업무 자동화 교육 사이트입니다.

## 바로 보기
- index.html을 브라우저로 열면 됩니다. 설치·빌드·계정 로그인이 필요 없습니다.
- 전체 사이트와 실습자료는 외부 라이브러리·웹폰트·이미지 서버 없이 동작합니다.
- 인터넷은 Microsoft 공식 문서나 실제 Power Automate 포털을 방문할 때 필요합니다.
- GitHub 저장소 화면 자체는 웹사이트 실행 화면이 아닙니다. 공개 배포는 별도 결정합니다.

## 구성

클라우드 자동화 전용 교육입니다. 40~50분은 SharePoint 첨부 저장 5분과 Excel 미완료 업무 요약 5분으로 진행합니다.

- 1시간 시작 코스: 개념/준비 10분 → 본인 메일 10분 → 메일-Teams 20분 → 활용 시연 10분 → 확인/중지 10분
- 10개 레슨, 단계별 안내 53개, 완료 체크와 브라우저 로컬 진도
- Outlook·Teams·SharePoint·Excel 클라우드 실습 4개
- 계정 연결 없는 메일→Teams 가상 연습: 필터 일치/불일치
- 16개 쉬운 용어, 오류 해결 FAQ, 쉬운 10문제 이해도 체크
- 60분 수업 타이머, 검색, 인쇄용 스타일
- Microsoft Learn 공식 출처 11개, 확인일 2026-11-03

## 파일

GitHub에는 독립형 index.html과 설명, 실습자료 묶음 practice-materials.zip을 저장합니다. 아래 materials/ 파일은 ZIP을 풀면 확인할 수 있고, 사이트 자료실에서도 개별 다운로드할 수 있습니다.
- index.html: CSS/JS/교육 데이터/다운로드 자료를 포함한 독립형 사이트
- materials/sample-tasks.xlsx: Tasks 테이블, 가상 업무 5건, 미완료 3건
- materials/sample-notice.txt: SharePoint 첨부 저장용 가상 파일
- materials/test-email.txt: 본인 테스트 메일 예시
- materials/automation-canvas.md: 업무 자동화 설계 템플릿

자료실 버튼은 동일한 파일을 HTML 안에 내장한 데이터에서 다운로드합니다. 따라서 index.html 한 개만 전달해도 기본 학습과 자료 다운로드가 됩니다. 자료를 수정할 때는 HTML의 MATERIALS 데이터도 함께 갱신해야 합니다.

## 안전과 검증 경계
- 모든 예시·업무·인물·파일은 자체 생성한 가상 교육 자료입니다.
- 이 사이트는 Microsoft 공식 사이트가 아니며 Microsoft 제품명은 설명 목적으로만 사용합니다.
- 공식 문서 기반의 교육용 구성입니다. 실제 회사 계정의 UI·권한·라이선스·조직 정책·흐름 실행은 검증하지 않았습니다.
- 실제 메일/Teams 발송, 파일 업로드, 계정 인증, PC 제어, AI API는 없습니다. 브라우저 가상 연습을 실제 실행 성공으로 표시하지 않습니다.
- CSP의 connect-src none으로 외부 API 연결을 제한합니다. 추적 스크립트·분석·외부 웹폰트가 없습니다.
- 완료 체크는 현재 브라우저의 localStorage(flow-class-v1)에만 저장됩니다. 계정 동기화·출결·공식 수료 인증이 아닙니다.
- 타이머·퀴즈는 현재 탭의 메모리에서만 유지됩니다. 새로고침하면 초기화됩니다.
- 예약 실행·프리미엄 커넥터·AI Builder는 기본 실습에서 제외하며 별도 조건을 확인합니다.
- 실습용 Excel의 DueDate는 고정 ISO 날짜 텍스트입니다. 기본 예제는 Status만 필터링하며 날짜 계산은 하지 않습니다.
- 실제 업무자료·계정·내부 링크·인증정보를 이 저장소에 넣지 마세요.

## 로컬 서버로 보기 (선택)
Python이 설치되어 있다면 이 폴더에서 다음을 실행합니다.

    python -m http.server 8765 --bind 127.0.0.1

그 후 http://127.0.0.1:8765/ 에 접속합니다. 단순 파일 열기로도 이용 가능합니다.

## 문서 관리
공식 문서는 변경될 수 있습니다. 교육 전 영어 액션명과 버전, Teams Workflows 허용·표준 채널 게시, Excel 테이블과 제한, 실제 수강생 계정의 연결을 다시 확인하세요. 공개 배포 전에는 회사 정보와 라이선스·호스팅 정책을 별도 검토하세요.

## 독립 검토 반영
- 본인 메일 대체안은 출력 제목을 [교육결과] 알림 확인으로 고정해 입력 제목 필터와 불일치시켜 재귀 발송을 방지하도록 안내합니다.
- Excel 요약 메일의 제목·수신자·본문을 모두 명시했습니다.
- 작은 화면의 메뉴에는 독립 스크롤과 키보드 포커스 처리를 적용했습니다.

## 확인한 기능
브라우저에서 홈·코스·레슨 탐색, 단계 펼치기, 완료 체크와 새로고침 후 유지, 기록 초기화, 검색, 가상 연습의 필터 일치/불일치, 10문제 퀴즈와 즉시 해설·10점 만점 채점, Excel 다운로드, 모바일 메뉴를 확인했습니다. Excel은 Tasks 테이블 A1:E6·데이터 5행·미완료 3행·ZIP 무결성을 확인했으며 수식은 없습니다. 실제 Power Automate 연결·발송·조직 환경은 미검증입니다.
